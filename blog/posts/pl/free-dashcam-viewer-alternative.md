**Dashcam Viewer** firmy Earthshine Software to jeden z najbardziej znanych programów do oglądania nagrań z kamer samochodowych na Windows i Macu. Obsługuje długą listę kamer i jest szczególnie mocny w GPS. Jego zaawansowane funkcje są dostępne po wykupieniu licencji, a program trzeba zainstalować na komputerze.

Jeśli chcesz czegoś darmowego, czego możesz użyć od razu, bez instalowania, alternatywą jest [Tripframe](/). Oto jak się porównują.

## Obok siebie

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Cena | Za darmo, open source (MIT) | Wersja darmowa; płatna licencja na zaawansowane funkcje |
| Instalacja | Brak, działa w przeglądarce | Aplikacja na Windows i Maca |
| Sortowanie klipów według dnia i godziny | Tak | Tak |
| Przód, tył i wnętrze zsynchronizowane | Tak | Tak |
| Etykiety zdarzeń i parkingu | Tak | Tak |
| Przechodzenie klatka po klatce | Tak | Tak |
| Zapis pojedynczej klatki | Tak, PNG nazwany dokładną godziną | Tak |
| Nagrywanie widoku jako nowego wideo | Tak, razem z mapą | Brak odpowiednika |
| Trasa GPS i prędkość na mapie | Viofo (Novatek) i BlackVue | Wiele marek |
| Eksport GPS (GPX, KML, CSV) | Tak, dla Viofo (Novatek) i BlackVue | Tak, wiele marek |
| Wykresy telemetrii (czujnik G, wysokość) | Nie | Tak |
| Wymagane konto | Nie | Nie |
| Wysyłanie nagrań | Nigdy | Nie |

## Kiedy Tripframe jest lepszym wyborem

- **Chcesz obejrzeć nagrania teraz.** Otwórz stronę, wybierz kartę, gotowe.
- **Pracujesz na komputerze, na którym nie możesz instalować oprogramowania**, na przykład na służbowym laptopie.
- **Chcesz mieć coś za darmo**, bez ograniczeń w używanych funkcjach.
- **Cenisz open source.** Kod jest [na GitHubie](https://github.com/JJanyar/tripframe).

## Kiedy Dashcam Viewer jest lepszym wyborem

- **Potrzebujesz telemetrii**, na przykład wykresów przeciążeń.
- **Format GPS Twojej marki nie jest jeszcze obsługiwany przez Tripframe**, jak Thinkware, Nextbase czy Garmin.
