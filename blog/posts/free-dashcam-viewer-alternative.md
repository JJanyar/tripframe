**Dashcam Viewer**, by Earthshine Software, is one of the best-known programs for watching dashcam footage on Windows and Mac. It supports a long list of cameras and is especially strong on GPS. Its advanced features sit behind a paid licence, and it is a desktop install.

If you want something free that you can use right now, without installing anything, [Tripframe](/) is an alternative. Here is how they compare.

## Side by side

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Price | Free, open source (MIT) | Free version; paid licence for advanced features |
| Install | None, runs in the browser | Desktop app for Windows and Mac |
| Sort clips by day and time | Yes | Yes |
| Front, rear and interior in sync | Yes | Yes |
| Event and parking labels | Yes | Yes |
| Frame-by-frame stepping | Yes | Yes |
| Save a still frame | Yes, PNG named after the exact time | Yes |
| Record the view as a new video | Yes, including the map | No equivalent |
| GPS route and speed on a map | Viofo (Novatek) and BlackVue | Many brands |
| GPS export (GPX, KML, CSV) | No | Yes |
| Telemetry graphs (G-sensor, altitude) | No | Yes |
| Account needed | No | No |
| Footage uploaded | Never | No |

## Where Tripframe is the better choice

- **You want to look at footage now.** Open a web page, choose the card, done.
- **You are on a computer you cannot install software on**, like a work laptop.
- **You want it free**, without limits on the features you use.
- **You care about open source.** The code is [on GitHub](https://github.com/JJanyar/tripframe).

## Where Dashcam Viewer is the better choice

- **You need GPS data out of the footage**, as GPX or KML for mapping or evidence.
- **You need telemetry**, like G-force graphs.
- **Your brand's GPS format is not supported by Tripframe yet**, such as Thinkware, Nextbase or Garmin.

[Open your dashcam folder in Tripframe](/app/). It takes about ten seconds to see whether it fits how you work, and nothing is uploaded.
