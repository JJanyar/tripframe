ドライブレコーダーはどれもきれいな映像を録画します。問題はそれを見ることです。わかりにくい名前のファイルが並ぶカード、前方と後方に分かれた映像、別のフォルダに入ったイベント録画。適切なソフトがあれば、これを実際に使える形にできます。

先にお断りすると、Tripframe は私たちが作っているため、このリストの最初に置いています。他のソフトのほうが優れている点も、公平に書くようにしました。

## 良いドラレコソフトの条件

- クリップをファイル名ではなく**日付と時刻**順に並べる
- **前方と後方を一緒に**同期再生する
- **イベントと駐車監視**のクリップを区別して表示する
- **1コマずつ**進めて、きれいな静止画を保存できる
- 地図上に**GPS ルートと速度**を表示する
- **複数のブランド**に対応する

## 1. Tripframe：インストール不要の無料ビューアで最良

[Tripframe](/) はブラウザで動きます。SD カードを開くと、すべてのクリップが日付と時刻ごとに並び、前方・後方・車内カメラがひとつの場面にまとまります。

- Viofo、BlackVue、Thinkware、70mai、Nextbase のファイル名に加え、Tesla、GoPro、日付を含むあらゆる名前を認識
- トリップごとの長さと間隔、すべてのクリップの最高速度を表示
- 同期カメラ：並べて表示、ピクチャー・イン・ピクチャー（サイズ変更可）、1台のカメラ表示、ズーム
- コマ送り、PNG・JPG・BMP での静止画保存、現在の表示（地図を含む）の動画録画
- クリップの一部を速く、遅く、逆再生で書き出し、トリップを再エンコードなしで 1 本の動画に結合
- Viofo（Novatek）、BlackVue、GoPro のファイルから GPS ルート、速度、標高、G フォースを取得。グラフ、マーカー、GPX・KML・CSV・GeoJSON での書き出しに対応
- 音声から大きな音を検出
- 無料のオープンソース、アカウント不要、**何もアップロードされません**

弱点：カメラの設定は変更できません。また、Thinkware、Nextbase、Garmin、70mai の GPS にはまだ対応していません。

## 2. Dashcam Viewer（Earthshine Software）

Windows と Mac 向けの老舗デスクトップアプリで、140 以上のカメラモデルを読み取れるほど GPS の対応範囲が広いのが特長です。テレメトリのグラフ、GPS の書き出し、クリップの書き出し、クリップの結合がそろっています。無料版は一度に 2 ファイルまでしか開けず、Plus と Pro のライセンスで制限が外れます。[Dashcam Viewer の無料の代替](/blog/free-dashcam-viewer-alternative/)との比較もご覧ください。

## 3. Registrator Viewer

多くのカメラに対応し、地図上に GPS を表示する無料の Windows ソフトです。高機能ですが、画面は古めかしく、Windows 専用です。

## 4. ブランド純正ソフト

BlackVue Viewer、Thinkware Dashcam Viewer、MyNextbase Player は自社ブランドには使いやすく、カメラの設定も変更できることが多いです。Viofo と 70mai は、ほぼアプリ専用です。[ドラレコブランド純正アプリの代替](/blog/alternatives-to-dashcam-brand-apps/)もお読みください。

## 5. 一般的な動画プレーヤー（VLC、Windows Media Player）

どんなファイルでも 1 本なら再生できますが、日付、カメラ、イベントのことは何も知りません。クリップ 1 本なら十分でも、ドライブ全体を見るのは大変です。

まずは [Tripframe](/app/) から。無料で、試すのに 10 秒もかかりません。お使いのカメラが Tripframe でまだ読み取れない形式で GPS を保存している場合は、Dashcam Viewer を追加してください。
