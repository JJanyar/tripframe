GPS 付きのドライブレコーダーは、どこにいたか、どのくらいの速度で走っていたかを毎秒記録します。事故のあとには、これが大きな意味を持つことがあります。速度が制限内だったことや、何がどこで起きたかを正確に示せるからです。ところが、カードの中に GPS 専用のファイルは見当たりません。データは動画の中に隠れているのです。

## GPS データの保存場所

| ブランド | GPS の保存方法 |
|---|---|
| Viofo などの Novatek 系カメラ | MP4 ファイルの中、よく「freeGPS」と呼ばれるブロック |
| BlackVue | MP4 ファイル内の NMEA センテンス |
| Thinkware | ファイル内、Thinkware 独自の形式 |
| Nextbase | ファイル内、Nextbase 独自の形式 |
| Garmin | ファイル内、Garmin 独自の形式 |
| GoPro | ファイル内の別のテレメトリトラック（GPMF）。標高と加速度センサーを含む |
| Tesla | ドラレコのファイルには保存されない |

通常の動画プレーヤーは、このデータを完全に無視します。どこを見ればよいかを知っているソフトが必要です。

## 動画の横でルートを見る

[Tripframe](/app/) は **Viofo / Novatek**、**BlackVue**、**GoPro** のファイルから GPS を読み取ります。

1. Tripframe でカードを開きます。
2. クリップを開き、`G` を押すか **地図** をクリックします。

動画の横に、クリップのルートを示す地図が表示されます。再生に合わせて矢印が車の位置を追い、地図の下に速度、方位、距離が km/h または mph で表示されます。地図・衛星・ハイブリッド表示を切り替えたり、ルートを速度で色分けしたりできます。`R` を押すと、動画と地図をひとつのファイルに一緒に録画します。

地図の下のグラフには、速度、距離、方位のほか、カメラが記録していれば標高、勾配、G フォース、衛星数が表示されます。グラフをクリックすると、その場面にジャンプします。`T` でルートにマーカーを置き、`H` で動画の上に走行データを表示します。

地図の画像は OpenStreetMap、衛星表示は Esri から取得します。天気と住所は、オンにした場合のみ調べます。映像と GPS データはパソコンに残ります。

## GPS データの書き出し

ルートをファイルとして使いたいですか？ Tripframe の地図の下で、**GPX**（ほとんどの地図・スポーツアプリ向け）、**KML**（Google Earth 向け）、**CSV**（すべてのポイントの時刻、位置、速度、方位、標高を含む表計算用）、**GeoJSON**（GIS ツール向け）を選べます。Tripframe がまだ読み取れないブランドには、Dashcam Viewer や Registrator Viewer などのデスクトップソフトを使ってください。[おすすめのドラレコソフト](/blog/best-dashcam-software/)をご覧ください。

## GPS が表示されない場合

- カメラの設定で GPS がオンになっているか、GPS マウントやモジュールが接続されているか確認してください。
- 始動直後の数分は、カメラが衛星を捕捉するまで GPS が取れないことがあります。
- お使いのブランドが、Tripframe がまだ読み取れない形式を使っている可能性があります。動画は通常どおり再生できます。
