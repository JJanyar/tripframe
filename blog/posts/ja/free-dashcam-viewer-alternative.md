Earthshine Softwareの**Dashcam Viewer**は、WindowsとMacでドライブレコーダーの映像を見るための、最もよく知られたプログラムのひとつです。多くのカメラに対応しており、特にGPSに強みがあります。一方で、高度な機能は有料ライセンスの向こう側にあり、デスクトップへのインストールが必要です。

インストールなしで、今すぐ無料で使えるものが欲しいなら、[Tripframe](/) が選択肢になります。両者を比べてみましょう。

## 比較表

| | Tripframe | Dashcam Viewer |
|---|---|---|
| 価格 | 無料、オープンソース（MIT） | 無料版あり。高度な機能は有料ライセンス |
| インストール | 不要、ブラウザで動作 | WindowsとMac用のデスクトップアプリ |
| クリップを日付と時刻で並べ替え | あり | あり |
| 前方・後方・車内の同期 | あり | あり |
| イベントと駐車監視のラベル | あり | あり |
| コマ送り | あり | あり |
| 静止画の保存 | あり、正確な時刻を名前にしたPNG | あり |
| 表示を新しい動画として録画 | あり、地図も含む | 同等の機能なし |
| GPSの走行ルートと速度を地図に表示 | Viofo（Novatek）とBlackVue | 多くのブランド |
| GPSの書き出し（GPX、KML、CSV） | あり、Viofo（Novatek）とBlackVue | あり、多くのブランド |
| テレメトリーのグラフ（Gセンサー、高度） | なし | あり |
| アカウントが必要か | 不要 | 不要 |
| 映像のアップロード | 一切なし | なし |

## Tripframeのほうが適している場合

- **今すぐ映像を見たい。** ウェブページを開き、カードを選べば完了です。
- **ソフトウェアをインストールできないパソコンを使っている**、たとえば会社のノートパソコン。
- **無料で使いたい**、しかも使う機能に制限なく。
- **オープンソースを重視する。** コードは[GitHub上](https://github.com/JJanyar/tripframe)にあります。

## Dashcam Viewerのほうが適している場合

- **テレメトリーが必要**、たとえばG-forceのグラフなど。
- **お使いのブランドのGPS形式にTripframeがまだ対応していない**、たとえばThinkware、Nextbase、Garminなど。
