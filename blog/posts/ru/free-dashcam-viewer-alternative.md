**Dashcam Viewer** от Earthshine Software — одна из самых известных программ для просмотра записей видеорегистраторов на Windows и Mac. Она поддерживает длинный список камер и особенно сильна в GPS. Расширенные функции доступны по платной лицензии, и программу нужно устанавливать на компьютер.

Если вам нужно что-то бесплатное, чем можно пользоваться прямо сейчас и ничего не устанавливая, альтернативой может стать [Tripframe](/). Вот как они сравниваются.

## Бок о бок

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Цена | Бесплатно, открытый исходный код (MIT) | Бесплатная версия; платная лицензия для расширенных функций |
| Установка | Не нужна, работает в браузере | Настольное приложение для Windows и Mac |
| Сортировка клипов по дню и времени | Да | Да |
| Передняя, задняя и салонная синхронно | Да | Да |
| Метки событий и парковки | Да | Да |
| Покадровое перемещение | Да | Да |
| Сохранение кадра | Да, PNG с точным временем в имени | Да |
| Запись вида в новое видео | Да, включая карту | Аналога нет |
| Маршрут GPS и скорость на карте | Viofo (Novatek) и BlackVue | Многие бренды |
| Экспорт GPS (GPX, KML, CSV) | Да, для Viofo (Novatek) и BlackVue | Да, многие бренды |
| Графики телеметрии (G-сенсор, высота) | Нет | Да |
| Нужен аккаунт | Нет | Нет |
| Загрузка записей | Никогда | Нет |

## Где Tripframe лучше

- **Вы хотите посмотреть записи прямо сейчас.** Открыли веб-страницу, выбрали карту, готово.
- **Вы за компьютером, на который нельзя устанавливать программы**, например за рабочим ноутбуком.
- **Вы хотите бесплатно**, без ограничений на нужные вам функции.
- **Для вас важен открытый исходный код.** Код [на GitHub](https://github.com/JJanyar/tripframe).

## Где Dashcam Viewer лучше

- **Вам нужна телеметрия**, например графики перегрузок.
- **Формат GPS вашего бренда пока не поддерживается в Tripframe**, например Thinkware, Nextbase или Garmin.
