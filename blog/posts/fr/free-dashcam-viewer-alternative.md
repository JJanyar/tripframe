**Dashcam Viewer**, d’Earthshine Software, est l’un des programmes les plus connus pour regarder des vidéos de dashcam sous Windows et Mac. Il prend en charge une longue liste de caméras et se montre particulièrement fort sur le GPS. Ses fonctions avancées sont derrière une licence payante, et il faut l’installer sur l’ordinateur.

Si vous voulez quelque chose de gratuit, utilisable tout de suite et sans rien installer, [Tripframe](/) est une alternative. Voici comment ils se comparent.

## Côte à côte

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Prix | Gratuit, open source (MIT) | Version gratuite ; licence payante pour les fonctions avancées |
| Installation | Aucune, fonctionne dans le navigateur | Application de bureau pour Windows et Mac |
| Tri des clips par jour et heure | Oui | Oui |
| Avant, arrière et intérieur synchronisés | Oui | Oui |
| Étiquettes d’événement et de stationnement | Oui | Oui |
| Avance image par image | Oui | Oui |
| Enregistrer une image fixe | Oui, PNG nommé d’après l’heure exacte | Oui |
| Enregistrer la vue sous forme de nouvelle vidéo | Oui, carte comprise | Pas d’équivalent |
| Itinéraire GPS et vitesse sur une carte | Viofo (Novatek) et BlackVue | Nombreuses marques |
| Export GPS (GPX, KML, CSV) | Oui, pour Viofo (Novatek) et BlackVue | Oui, nombreuses marques |
| Graphiques de télémétrie (capteur de choc, altitude) | Non | Oui |
| Compte nécessaire | Non | Non |
| Envoi des vidéos | Jamais | Non |

## Quand Tripframe est le meilleur choix

- **Vous voulez regarder des vidéos maintenant.** Ouvrez une page web, choisissez la carte, c’est fait.
- **Vous êtes sur un ordinateur où vous ne pouvez pas installer de logiciel**, comme un portable professionnel.
- **Vous le voulez gratuit**, sans limite sur les fonctions que vous utilisez.
- **L’open source compte pour vous.** Le code est [sur GitHub](https://github.com/JJanyar/tripframe).

## Quand Dashcam Viewer est le meilleur choix

- **Vous avez besoin de télémétrie**, par exemple des graphiques de force G.
- **Le format GPS de votre marque n’est pas encore pris en charge par Tripframe**, comme Thinkware, Nextbase ou Garmin.

## Essayez-le

[Ouvrez le dossier de votre dashcam dans Tripframe](/app/). Il suffit d’une dizaine de secondes pour voir s’il correspond à votre façon de travailler, et rien n’est envoyé.
