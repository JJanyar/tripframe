**Dashcam Viewer** von Earthshine Software ist eines der bekanntesten Programme, um Dashcam-Aufnahmen unter Windows und Mac anzusehen. Es unterstützt eine lange Liste von Kameras und ist besonders stark bei GPS. Die erweiterten Funktionen stecken hinter einer kostenpflichtigen Lizenz, und es muss auf dem Computer installiert werden.

Wenn du etwas Kostenloses willst, das du sofort und ohne Installation nutzen kannst, ist [Tripframe](/) eine Alternative. So schneiden die beiden im Vergleich ab.

## Gegenüberstellung

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Preis | Kostenlos, Open Source (MIT) | Kostenlose Version; kostenpflichtige Lizenz für erweiterte Funktionen |
| Installation | Keine, läuft im Browser | Desktop-App für Windows und Mac |
| Clips nach Tag und Uhrzeit sortieren | Ja | Ja |
| Front, Heck und Innen synchron | Ja | Ja |
| Ereignis- und Parkkennzeichnung | Ja | Ja |
| Bild-für-Bild-Schaltung | Ja | Ja |
| Standbild speichern | Ja, PNG nach der genauen Zeit benannt | Ja |
| Ansicht als neues Video aufzeichnen | Ja, einschließlich Karte | Kein Gegenstück |
| GPS-Route und Geschwindigkeit auf einer Karte | Viofo (Novatek) und BlackVue | Viele Marken |
| GPS-Export (GPX, KML, CSV) | Ja, für Viofo (Novatek) und BlackVue | Ja, viele Marken |
| Telemetrie-Diagramme (G-Sensor, Höhe) | Nein | Ja |
| Konto nötig | Nein | Nein |
| Aufnahmen hochgeladen | Nie | Nein |

## Wo Tripframe die bessere Wahl ist

- **Du willst Aufnahmen jetzt ansehen.** Webseite öffnen, Karte wählen, fertig.
- **Du sitzt an einem Computer, auf dem du keine Software installieren kannst**, etwa einem Firmenlaptop.
- **Du willst es kostenlos**, ohne Einschränkungen bei den Funktionen, die du nutzt.
- **Dir ist Open Source wichtig.** Den Code findest du [auf GitHub](https://github.com/JJanyar/tripframe).

## Wo Dashcam Viewer die bessere Wahl ist

- **Du brauchst Telemetrie**, etwa G-Kraft-Diagramme.
- **Das GPS-Format deiner Marke wird von Tripframe noch nicht unterstützt**, etwa bei Thinkware, Nextbase oder Garmin.

[Öffne deinen Dashcam-Ordner in Tripframe](/app/). In etwa zehn Sekunden siehst du, ob es zu deiner Arbeitsweise passt, und nichts wird hochgeladen.
