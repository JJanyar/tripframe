**Dashcam Viewer** van Earthshine Software is een van de bekendste programma's om dashcambeelden op Windows en Mac te bekijken. Het ondersteunt een lange lijst camera's en is vooral sterk in GPS. De geavanceerde functies zitten achter een betaalde licentie en het is een installatie op je computer.

Wil je iets gratis dat je meteen kunt gebruiken, zonder iets te installeren, dan is [Tripframe](/) een alternatief. Zo verhouden ze zich tot elkaar.

## Naast elkaar

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Prijs | Gratis, open source (MIT) | Gratis versie; betaalde licentie voor geavanceerde functies |
| Installatie | Geen, draait in de browser | Desktop-app voor Windows en Mac |
| Opnames sorteren op dag en tijd | Ja | Ja |
| Voor, achter en binnen synchroon | Ja | Ja |
| Event- en parkeerlabels | Ja | Ja |
| Beeld voor beeld doorlopen | Ja | Ja |
| Een still opslaan | Ja, PNG genoemd naar de exacte tijd | Ja |
| De weergave als nieuwe video opnemen | Ja, inclusief de kaart | Geen equivalent |
| GPS-route en snelheid op een kaart | Viofo (Novatek) en BlackVue | Veel merken |
| GPS-export (GPX, KML, CSV) | Ja, voor Viofo (Novatek) en BlackVue | Ja, veel merken |
| Telemetriegrafieken (G-sensor, hoogte) | Nee | Ja |
| Account nodig | Nee | Nee |
| Beelden geüpload | Nooit | Nee |

## Waar Tripframe de betere keuze is

- **Je wilt nu beelden bekijken.** Open een webpagina, kies de kaart, klaar.
- **Je zit op een computer waarop je geen software mag installeren**, zoals een laptop van je werk.
- **Je wilt het gratis**, zonder beperkingen op de functies die je gebruikt.
- **Open source is belangrijk voor je.** De code staat [op GitHub](https://github.com/JJanyar/tripframe).

## Waar Dashcam Viewer de betere keuze is

- **Je hebt telemetrie nodig**, zoals G-krachtgrafieken.
- **Het GPS-formaat van jouw merk wordt nog niet door Tripframe ondersteund**, zoals bij Thinkware, Nextbase of Garmin.
