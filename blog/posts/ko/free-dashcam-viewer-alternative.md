Earthshine Software의 **Dashcam Viewer**는 Windows와 Mac에서 블랙박스 영상을 보는 가장 잘 알려진 프로그램 중 하나입니다. 지원하는 카메라가 많고 특히 GPS에 강합니다. 고급 기능은 유료 라이선스가 필요하고, 데스크톱에 설치해야 합니다.

아무것도 설치하지 않고 지금 바로 쓸 수 있는 무료 도구를 원한다면 [Tripframe](/)이 대안이 될 수 있습니다. 두 도구를 비교해 볼게요.

## 나란히 비교

| | Tripframe | Dashcam Viewer |
|---|---|---|
| 가격 | 무료, 오픈 소스 (MIT) | 무료 버전, 고급 기능은 유료 라이선스 |
| 설치 | 없음, 브라우저에서 실행 | Windows와 Mac용 데스크톱 앱 |
| 날짜와 시간별 클립 정렬 | 지원 | 지원 |
| 전방, 후방, 실내 동기화 | 지원 | 지원 |
| 이벤트와 주차 라벨 | 지원 | 지원 |
| 프레임 단위 이동 | 지원 | 지원 |
| 정지 화면 저장 | 지원, 정확한 시간으로 이름 붙인 PNG | 지원 |
| 화면을 새 동영상으로 녹화 | 지원, 지도 포함 | 해당 기능 없음 |
| 지도에 GPS 경로와 속도 표시 | Viofo (Novatek)와 BlackVue | 많은 브랜드 |
| GPS 내보내기 (GPX, KML, CSV) | 지원, Viofo (Novatek)와 BlackVue | 지원, 많은 브랜드 |
| 텔레메트리 그래프 (G센서, 고도) | 미지원 | 지원 |
| 계정 필요 | 아니요 | 아니요 |
| 영상 업로드 | 하지 않음 | 아니요 |

## Tripframe이 더 나은 경우

- **지금 바로 영상을 보고 싶을 때.** 웹 페이지를 열고 카드를 선택하면 끝입니다.
- **회사 노트북처럼 소프트웨어를 설치할 수 없는 컴퓨터**를 쓸 때.
- **무료**로, 쓰는 기능에 제한 없이 쓰고 싶을 때.
- **오픈 소스**가 중요할 때. 코드는 [GitHub에](https://github.com/JJanyar/tripframe) 있습니다.

## Dashcam Viewer가 더 나은 경우

- G포스 그래프 같은 **텔레메트리**가 필요할 때.
- Thinkware, Nextbase, Garmin처럼 **사용 중인 브랜드의 GPS 형식을 Tripframe이 아직 지원하지 않을 때**.
