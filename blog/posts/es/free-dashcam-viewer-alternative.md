**Dashcam Viewer**, de Earthshine Software, es uno de los programas más conocidos para ver grabaciones de dashcam en Windows y Mac. Admite una larga lista de cámaras y destaca sobre todo en GPS. Sus funciones avanzadas están tras una licencia de pago, y hay que instalarlo en el ordenador.

Si quieres algo gratuito que puedas usar ya, sin instalar nada, [Tripframe](/) es una alternativa. Así se comparan.

## Cara a cara

| | Tripframe | Dashcam Viewer |
|---|---|---|
| Precio | Gratis, código abierto (MIT) | Versión gratuita; licencia de pago para funciones avanzadas |
| Instalación | Ninguna, funciona en el navegador | App de escritorio para Windows y Mac |
| Ordenar clips por día y hora | Sí | Sí |
| Delantera, trasera e interior sincronizadas | Sí | Sí |
| Etiquetas de evento y aparcamiento | Sí | Sí |
| Avance fotograma a fotograma | Sí | Sí |
| Guardar un fotograma | Sí, PNG con el nombre de la hora exacta | Sí |
| Grabar la vista como vídeo nuevo | Sí, incluido el mapa | Sin equivalente |
| Ruta GPS y velocidad en un mapa | Viofo (Novatek) y BlackVue | Muchas marcas |
| Exportación GPS (GPX, KML, CSV) | Sí, para Viofo (Novatek) y BlackVue | Sí, muchas marcas |
| Gráficos de telemetría (sensor G, altitud) | No | Sí |
| Requiere cuenta | No | No |
| Sube las grabaciones | Nunca | No |

## Dónde Tripframe es la mejor opción

- **Quieres ver las grabaciones ahora.** Abre una página web, elige la tarjeta y listo.
- **Estás en un ordenador donde no puedes instalar software**, como un portátil del trabajo.
- **Lo quieres gratis**, sin límites en las funciones que usas.
- **Te importa el código abierto.** El código está [en GitHub](https://github.com/JJanyar/tripframe).

## Dónde Dashcam Viewer es la mejor opción

- **Necesitas telemetría**, como gráficos de fuerza G.
- **El formato GPS de tu marca todavía no es compatible con Tripframe**, como Thinkware, Nextbase o Garmin.
